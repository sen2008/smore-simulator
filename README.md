# Smore Simulator

A pixelated campfire s'mores-making game. Roast a marshmallow over a crackling pixel fire, then stack it between graham crackers and chocolate for points.

## How to play

Open `index.html` in a browser (no build step, no dependencies).

- **Move** the roasting stick with your mouse or arrow keys.
- Hold the marshmallow **over the flames** to roast it. It goes white → golden → dark → burnt.
- **G** — place graham cracker, **C** — chocolate, **M** — marshmallow, **N** — toss for a fresh mallow, **E** — eat the finished s'more.
- Stack order matters: graham → chocolate → mallow → graham.
- 90 seconds on the clock. Golden marshmallows are worth 100 pts; burnt ones, a sad 10.
